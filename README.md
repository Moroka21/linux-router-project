# Linux Router Project

## Overview
This project demonstrates how Ubuntu Linux was configured as a router in VirtualBox.

## Features
- IP forwarding
- NAT (Network Address Translation)
- DHCP server
- Firewall using iptables
- LAN to WAN routing
- File transfer testing

## Environment
- Ubuntu VM (Router)
- Kali Linux VM (Client)
- VirtualBox

## Network Configuration
- Router IP: 192.168.10.1
- LAN: 192.168.10.0/24
- DHCP Range: 192.168.10.10 - 192.168.10.200

## Testing Results
- Ping to router successful
- Internet access successful
- DNS resolution successful
- Secure file transfer successful
